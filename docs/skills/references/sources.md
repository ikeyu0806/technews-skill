# 情報源と探索先

ここは入口の候補一覧。各ページの提供状況や内容は実行時に確認する。過去の掲載記事や反応数は固定しない。指定分野に合う入口を選び、良い新しい情報源も発見する。

## 国内の入口

| 情報源 | 用途 |
| --- | --- |
| [はてなブックマーク IT](https://b.hatena.ne.jp/hotentry/it) | 技術記事、開発者の実録、人物発信、議論の発見とブックマーク数の確認 |
| [はてなブックマーク ゲーム](https://b.hatena.ne.jp/hotentry/game) | ゲーム分野の入口。作品ニュースから開発・技術に関係する話題を選ぶ |
| [Zenn](https://zenn.dev/)・[Qiita](https://qiita.com/) | 開発者の実験や知見。評価数だけでなく本文の検証・実装条件も確認 |
| [DevelopersIO](https://dev.classmethod.jp/) | クラウド、AI、実際に試した技術記事 |
| [Publickey](https://www.publickey1.jp/) | 開発基盤、OSS、クラウドの解説 |
| [PC Watch](https://pc.watch.impress.co.jp/)・[AV Watch](https://av.watch.impress.co.jp/) | PC、半導体、ガジェット、映像・音響機器 |
| [AUTOMATON](https://automaton-media.com/)・[CGWORLD](https://cgworld.jp/) | ゲーム業界、制作者の言動、3D・映像制作と技術 |

人気エントリーから元記事とブックマークの議論ページを開く。まとめや翻訳記事からは元の海外記事にも遡る。

検索語の例: physical AI、embodied AI、VLA、world model、sim-to-real、robot learning、manipulation、tactile、locomotion、autonomous drone。

デモが自律動作か遠隔操作か、編集済みか連続動作か、評価条件・試行数・失敗例・実機の有無を確認する。論文が出ただけなら探索枠として扱い、広くバズっているとは断定しない。

## 人物発信

関係する人物だけを探す。全員のSNSを毎回巡回しない。

- AI・開発: Simon Willison（[ブログ](https://simonwillison.net/)）、Andrej Karpathy、Linus Torvalds、主要AI研究者・ラボの発信。
- ゲーム・XR: Tim Sweeney、John Carmack、エンジン開発者、制作者の登壇・インタビュー。
- ハードウェア・ロボティクス: Jensen Huang、研究者や開発者、実機を公開するチーム。
- 国内: 安野貴博など、技術に関係する議論や実験を公開する人物・開発者。

本人のブログ、所属先の発表、リポジトリ、公式の登壇動画・ポッドキャスト、SNS投稿全文へ遡る。本人発言にアクセスできなければ、全文引用や文脈のある原報道を使い、その媒体経由の情報だと伝える。技術と無関係な人物の炎上だけで枠を埋めない。

## 新しい収集サイトを見つける

良い記事の著者サイト、リンク集・blogroll、HNや専門媒体の参照元を辿る。新しいサービスやデモ自体も候補にする。

収集元として紹介する場合は次を確認する。

- 誰が発行していて、どの分野を継続して扱っているか。
- 元記事、一次資料、著者、日付へ辿れるか。
- 今回の関心に合う記事、作品、議論を実際に見つけたか。
- 速報、投票型、専門解説、本人発信など、何のための入口か。
- 全文が読めるか、ログインや購読が必要か。取得できた範囲で判断する。

記事の中身を確認できない自動生成のまとめを唯一の出典にしない。RSSやAPIを使う場合はフィードを実際に確認し、URLを推測で作らない。良い情報源は採用理由とともに紹介し、この一覧の編集は依頼がある場合に行う。
